01

Features

Everything you need to build a polished UI without pulling in dependencies.

Auto Scale

Resizes to fit any viewport. Mobile, desktop, tablet. No manual sizing.

Drag Clamping

The window cannot be dragged off screen. Boundary math is built in.

Minimize to Opener

Collapses into a clean semi transparent widget. Drag it anywhere.

Search Filter

Type in the sidebar to filter every element across all tabs by name.

Custom Icons

Script icon in the header, plus optional icons per tab.

Profile Widget

Shows the local player's avatar, display name, and username.

Save and Load

Dump every flag to JSON. Restore them on next launch.

Slider Text Input

Drag the slider or type an exact value. Both work.

02

Installation

Add the library to your script with a single line. No external files, no setup.

lua 
local XevUI = loadstring(game:HttpGet("https://raw.githubusercontent.com/krislowk/XevUI/refs/heads/main/source/XevUI.lua"))()
Requirements. Any executor with HttpGet and loadstring support. Works on Delta, Codex, Wave, and every mainstream executor on mobile or desktop.
03

Quick Start

Create a window, add a tab, drop in a toggle. That's the whole flow.

lua 
local Window = XevUI:CreateWindow({
    Title = "My Hub",
    Subtitle = "V1",
    Icon = "rbxassetid://7733750337",
    Width = 440,
    Height = 320,
})

local Main = Window:CreateTab("Main")
local Section = Main:CreateSection("Visuals", "ESP settings")

Section:CreateToggle({
    Text = "Enable ESP",
    Flag = "ESP",
    Default = true,
    Callback = function(value)
        print("ESP:", value)
    end,
})
04

Window API

The object returned by XevUI:CreateWindow. Controls the entire UI.

MethodDescription
Window:CreateTab(name, iconId)Adds a tab. iconId is optional. Returns the Tab object.
Window:SelectTab(name)Switches to a specific tab by name.
Window:Notify(options)Shows a notification. Options: Title, Text, Duration.
Window:SaveConfig()Returns a JSON string of all current Flags.
Window:LoadConfig(json)Restores Flags from a JSON string.
Window:SetTitle(text)Updates the window title.
Window:SetSubtitle(text)Updates the window subtitle.
Window:Destroy()Destroys the UI.
05

Tab API

Each tab contains one or more sections. Sections group related elements.

MethodDescription
Tab:CreateSection(title, description)Creates a section. Description is optional. Returns the Section object.
Tab:CreateDivider()Adds a thin horizontal line between tabs.
Tab:Select()Activates this tab.
06

Elements

Every element accepts an optional Flag and Callback. When a Flag is provided, the current value is written to XevUI.Flags on change.

CreateButton CreateToggle CreateSlider CreateTextbox CreateDropdown CreateColorPicker CreateKeybind CreateLabel CreateParagraph CreateDivider

Button

lua 
Section:CreateButton({
    Text = "Click Me",
    Callback = function()
        Window:Notify({Title = "Clicked", Text = "Button pressed."})
    end,
})

Toggle

lua 
local toggle = Section:CreateToggle({
    Text = "Enable ESP",
    Flag = "ESP",
    Default = true,
    Callback = function(state)
        print("ESP:", state)
    end,
})

print(toggle:Get())
toggle:Set(false)

Slider

lua 
Section:CreateSlider({
    Text = "Render Distance",
    Flag = "RenderDistance",
    Min = 100,
    Max = 5000,
    Default = 1000,
    Suffix = "m",
    Callback = function(value)
        print("Distance:", value)
    end,
})

Dropdown

lua 
Section:CreateDropdown({
    Text = "Box Style",
    Flag = "BoxStyle",
    Options = {"2D", "3D", "Corner", "Filled"},
    Default = "2D",
    Callback = function(selected)
        print("Style:", selected)
    end,
})
07

Flags

Any element with a Flag string writes to XevUI.Flags when its value changes. Read the table directly anywhere in your script.

lua 
print(XevUI.Flags.ESP)
print(XevUI.Flags.RenderDistance)
print(XevUI.Flags.ESPColor)

game:GetService("RunService").Heartbeat:Connect(function()
    if XevUI.Flags.Aimbot then
        -- do aimbot thing
    end
end)
08

Save and Load

Dump every flag to JSON and restore it later. Color3 values are encoded with a type tag so they survive the round trip.

lua 
local json = Window:SaveConfig()
writefile("myhub_config.json", json)

local data = readfile("myhub_config.json")
Window:LoadConfig(data)
